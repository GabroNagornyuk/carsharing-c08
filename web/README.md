# Частина Web

Каталог починається з комплекту курсу «Обмін даними у Web-застосунках»
([a-kovt/web-interactions-course](https://github.com/a-kovt/web-interactions-course), MIT).
Опис системи, запуск і результати – у [кореневому README](../README.md).

| Шлях | Що це |
|---|---|
| `server/app/rentals.py`, `cars.py`, `users.py` | наш код: головна операція, продовження з If-Match, скасування, мої оренди, вільні авто, функція персоналу (ЛР3), вхід, вихід, сесії й обмеження спроб входу (ЛР3) |
| `server/app/browser.py` | наш код (ЛР3): перевірка `Origin` / `Sec-Fetch-Site` змінювальних запитів до виконання дії |
| `server/app/idempotency.py` | наш код (ЛР2): ключі ідемпотентності в одній транзакції з орендою, прибирання прострочених |
| `server/app/*` (інші модулі) | каркас комплекту: журнал, X-Request-ID, Problem Details, /health, пул БД |
| `openapi.yaml` | контракт частини Web |
| `client/` | вебклієнт; `api.js` – повтори з тим самим ключем і «результат невідомий» (ЛР2), вхід і cookie сесії (ЛР3) |
| `tools/evil-origin/` | сторінка «стороннього сайту» для О3.3 (комплект; адресу й тіло змінено на бронювання) |
| `configs/nginx/nginx.conf` | балансувальник (ЛР1 – лише app-a, app-b) |
| `configs/migrate/migrate.sh` | застосування SQL-міграцій з кореневого `migrations/` |
| `tools/`, `docs/`, `configs/*` | засоби комплекту для наступних ЛР |
